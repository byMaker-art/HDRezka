# HDRezka для Kodi (Python 3 / Matrix, Nexus, Omega, Piers v22)

Современный кроссплатформенный форк официального дополнения **HDRezka** (`plugin.video.hdrezka.tv`) для медиацентра **Kodi**.

### 🌟 Ключевые особенности форка

1. **Мгновенный автоматический обход защиты от ботов (Anubis Proof-of-Work)**:
   * На зеркале `kinopub.me` и других серверах установлена PoW-защита Anubis. Форк автоматически перехватывает челендж, вычисляет SHA-256 хэш в памяти за 1–2 миллисекунды, отправляет подтверждение и сохраняет авторизационные cookie. Никаких капч от пользователя не требуется.
2. **100% Сохранение существующей библиотеки и «Избранного» в Kodi**:
   * Идентификатор аддона сохранён прежним: `plugin.video.hdrezka.tv`.
   * Полная обратная совместимость со всеми ссылками, сериалами и фильмами, ранее добавленными в «Избранное» Kodi или виджеты главного экрана.
   * Автоматическая нормализация доменов: если ссылка в избранном сохранена со старым доменом, аддон автоматически перенаправляет запрос на активное рабочее зеркало из настроек.
3. **Авторизация в личном аккаунте HDRezka**:
   * Поддержка входа по логину/email и паролю.
   * Меню **«Мои закладки»** прямо в Kodi — ваши сохранённые на сайте фильмы и сериалы синхронизируются с аккаунтом.
   * Сессионные cookies сохраняются на диск между перезапусками Kodi.
4. **Кроссплатформенность и совместимость с Kodi 22 Piers (beta 2)**:
   * Работает на **Windows 11, Android TV / Android, macOS, Linux**.
   * Чистый Python 3: **ноль внешних бинарных зависимостей** (никаких проблем с компиляцией на архитектурах ARM/x86/x64).
   * Совместимость с новым VideoInfoTag API Kodi 20/21/22 и мягкий фоллбэк для старых версий.
5. **Надёжное воспроизведение видеопотоков**:
   * Автоматическая передача требуемых HTTP-заголовков (`User-Agent`, `Referer`) в плеер Kodi для исключения 403-ошибок с CDN Voidboost.
   * Поддержка выбора озвучки/перевода и качества (от 360p до 4K / 1080p Ultra).

### 📦 Установка

Готовый к установке архив находится в корне проекта:
**`plugin.video.hdrezka.tv-3.0.0.zip`**

#### На Windows 11 (Kodi 22 Piers):
1. Откройте **Kodi** → **Настройки (шестерёнка)** → **Система** → **Дополнения**.
2. Включите пункт **«Неизвестные источники»**.
3. Вернитесь в раздел **Дополнения** → выберите **«Установить из файла ZIP»**.
4. Укажите файл `plugin.video.hdrezka.tv-3.0.0.zip`.
5. Kodi обновит дополнение поверх старого с сохранением всех настроек и библиотеки.

#### На Android (Android TV / Приставка / Смартфон):
1. Передайте файл `plugin.video.hdrezka.tv-3.0.0.zip` на Android-устройство (через флешку, приложение *Send Files to TV*, или сетевую папку SMB).
2. В Kodi откройте **Дополнения** → **«Установить из файла ZIP»** → выберите переданный zip-файл.

### ⚙️ Настройки дополнения
* **Адрес сайта / зеркало**: по умолчанию `kinopub.me` (можно сменить на `rezka.ag` или любое персональное зеркало).
* **Качество видео**: выбор конкретного качества или «Всегда спрашивать».
* **Озвучка / перевод**: выбор приоритетной озвучки или диалог при запуске.
* **Аккаунт HDRezka**: укажите логин и пароль для доступа к разделу «Мои закладки».
* **Прокси**: поддержка HTTP/HTTPS и SOCKS5 прокси при необходимости.
