Форк официального дополнения **HDRezka** (`plugin.video.hdrezka.tv`) для медиацентра **Kodi**, восстанавливающий полную работоспособность популярного онлайн-кинотеатра на актуальных зеркалах (включая **kinopub.me**), с обходом антибот-защиты **Anubis PoW**, синхронизацией прогресса с личным кабинетом и поддержкой автоматических обновлений через собственный репозиторий.

---

## 🌟 Ключевые возможности и отличия форка

* **⚡ Автоматический обход бот-защиты Anubis Proof-of-Work (PoW)**:
  На зеркале `kinopub.me` включена криптографическая проверка браузера на основе SHA-256 (Anubis). Дополнение на лету перехватывает челлендж, вычисляет нужный хэш за 30–50 мс прямо в памяти, получает сессионные куки и прозрачно загружает видеопоток без каких-либо капч и пауз для пользователя.
* **🔄 Полное сохранение старого избранного и библиотеки**:
  Встроена автонормализация ссылок. Если в вашем Kodi уже были сохранены тайтлы со старыми доменами (`rezka.ag`, `hdrezka.ag` и др.), дополнение на лету подменяет адрес на текущий активный (`kinopub.me`). Все сохранённые фильмы и сериалы продолжают открываться!
* **⏱️ Двусторонняя облачная синхронизация («Продолжить просмотр»)**:
  Восстановлена и расширена интеграция фонового сервиса плеера (`HDRezkaPlayer`). При просмотре сериала или фильма в Kodi плеер каждые 60 секунд, а также при паузе и выходе, отправляет точную секунду просмотра в ваш личный кабинет HDRezka (`/ajax/send_save/`). Вы можете начать смотреть в Kodi на телевизоре, а продолжить с этой же минуты на телефоне или компьютере в браузере.
* **🌐 Онлайн-обновления без флешек (Kodi Repository)**:
  В проект включен готовый легковесный репозиторий `repository.hdrezka`. Достаточно установить его один раз, и все последующие версии дополнения будут обновляться автоматически через интернет.
* **📦 Полная автономность и кроссплатформенность**:
  Все необходимые библиотеки (`XbmcHelpers`, `Translit`, `SearchHistory`, `cache`, `HDRezkaPlayer`) запакованы внутрь дополнения. Оно гарантированно устанавливается на чистый Kodi (Windows 11, Android TV, macOS, Linux, LibreELEC / CoreELEC) без ошибок о недостающих внешних модулях.
* **🛠️ Исправление окна настроек**:
  Устранен скрытый байт-маркер UTF-8 BOM в `settings.xml`, из-за которого в Kodi 20/21/22 окно настроек открывалось пустым («Нет доступных категорий»). Добавлены функции безопасного выхода из аккаунта (**Logout**), валидация зеркала и очистка прокси.
* **🎬 Стабильное воспроизведение потоков Voidboost**:
  Передаются правильные HTTP-заголовки `Referer` и `User-Agent` для исключения ошибок `403 Forbidden`. Подключен `inputstream.adaptive` для бесшовного проигрывания HLS-плейлистов (`.m3u8`).

## 📥 Установка

### Способ 1: Через репозиторий (Рекомендуется — с автообновлениями)

1. Скачайте zip-файл репозитория: [**packages/repository.hdrezka-1.0.0.zip**](packages/repository.hdrezka-1.0.0.zip).
2. В Kodi откройте: **Настройки (шестеренка)** ➔ **Система** ➔ **Дополнения** ➔ включите пункт **«Неизвестные источники»**.
3. Вернитесь в **Дополнения** ➔ нажмите значок коробки (вверху слева) ➔ **«Установить из файла ZIP»** ➔ выберите `repository.hdrezka-1.0.0.zip`.
4. Затем выберите **«Установить из репозитория»** ➔ **HDRezka Repository** ➔ **Видеодополнения** ➔ **Hdrezka.tv** ➔ **Установить**.
5. *Готово!* Дополнение установится, и все последующие обновления будут прилетать автоматически через интернет.

---

### Способ 2: Прямая установка из ZIP

1. Скачайте последнюю версию дополнения: [**packages/plugin.video.hdrezka.tv-3.3.2.zip**](packages/plugin.video.hdrezka.tv-3.3.2.zip).
2. В Kodi перейдите в **Дополнения** ➔ **«Установить из файла ZIP»** ➔ выберите скачанный архив.
3. Дополнение обновится с сохранением всех настроек и аккаунта.

## ⚙️ Настройка и использование

1. Откройте **Дополнения** ➔ зажмите/кликните правой кнопкой мыши по **Hdrezka.tv** ➔ **Настройки**:
   * **Default**:
     * *Site URL*: по умолчанию выставлен `kinopub.me` (можно указать любое актуальное зеркало, префиксы `https://` дополнение очистит автоматически).
     * *Video quality*: выбор качества по умолчанию (`select` — спрашивать каждый раз, либо фиксированное `1080p`, `720p` и т.д.).
     * *Use translator*: выбор озвучки (`default` — запоминать или брать первую, `select` — предлагать выбор).
   * **Authorization**:
     * Введите ваш *Username* (логин или e-mail) и *Password*.
     * Нажмите **«Authorize»** — появится уведомление «Авторизация успешна».
     * Кнопка **«Logout»** позволяет в любой момент безопасно завершить сессию и очистить куки.
   * **Proxy settings**:
     * Если ваш провайдер блокирует само зеркало, можно включить прокси (HTTP или SOCKS5).

2. **Главное меню дополнения**:
   * **Поиск**: поиск по каталогу фильмов и сериалов (с поддержкой транслитерации).
   * **История поиска**: быстрый доступ к ранее найденным запросам.
   * **Продолжить просмотр**: список тайтлов, синхронизированных с вашим личным кабинетом HDRezka.
   * **Категории / Последние поступления / Популярные / Сейчас смотрят**: навигация по каталогу онлайн-кинотеатра.

## 📂 Структура проекта

```text
HDRezka/
├── addon.xml                 # Манифест Kodi-дополнения (версия 3.3.2)
├── default.py                # Главный скрипт плагина, роутинг, Anubis PoW solver
├── service.py                # Фоновый сервис для отслеживания просмотра и синхронизации
├── actions.py                # Обработчики авторизации, выхода из аккаунта и внешнего конфига
├── helpers.py                # Вспомогательные функции (куки, заголовки, логирование)
├── router.py                 # Маршрутизатор URI параметров Kodi
├── voidboost.py              # Парсер и расшифровщик видеопотоков плеера
├── socks.py                  # Поддержка SOCKS5 прокси
├── icon.png / fanart.jpg     # Оформление дополнения
├── changelog.txt             # История версий
├── LICENSE                   # Лицензия GNU General Public License v3
├── resources/
│   ├── settings.xml          # Окно настроек дополнения (UTF-8 clean)
│   ├── icons/                # Дополнительные графические иконки
│   ├── language/             # Локализация (русский ru_RU и английский en_GB)
│   └── lib/                  # Автономные модули (XbmcHelpers, Translit, cache, HDRezkaPlayer)
├── packages/                 # Готовые дистрибутивы для ручной установки
│   ├── plugin.video.hdrezka.tv-3.3.2.zip
│   └── repository.hdrezka-1.0.0.zip
├── repo/                     # Онлайн-репозиторий Kodi (для автообновлений через GitHub)
│   ├── addons.xml
│   ├── addons.xml.md5
│   └── zips/
├── repository.hdrezka/       # Исходный код дополнения-репозитория
└── tools/                    # Утилиты сборщика
    ├── build.py              # Сборка установочного ZIP плагина
    └── build_repo.py         # Полная сборка плагина, репозитория, addons.xml и md5
```

## 🛠️ Разработка и публикация новых версий

Для сборки свежих zip-архивов и обновления структуры репозитория запустите скрипт:

```bash
python3 tools/build_repo.py
```

Скрипт автоматически:
1. Считает текущую версию из `addon.xml`.
2. Соберет очищенные zip-архивы в папку `packages/`.
3. Обновит файлы репозитория в `repo/zips/`.
4. Сгенерирует актуальный `repo/addons.xml` и пересчитает `repo/addons.xml.md5`.

После этого достаточно закоммитить изменения и запушить их в ветку `main` вашего репозитория на GitHub:

```bash
git add -A
git commit -m "Release vX.X.X"
git push origin main
```

Все клиентские Kodi увидят обновление автоматически!
